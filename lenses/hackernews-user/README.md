# awe-lens-hackernews-user

A **awe Lens** that renders `hackernews.user`-matched URLs as a clean structured view inside an awe chat.

> Show a Hacker News user profile: karma, account age, about text, and latest 5 submissions — pulled live from the Firebase API.

## Install

```bash
awe-core lenses install https://github.com/awehq/community#lenses/hackernews-user
```

Or paste the URL into **+ Add lens** in the gateway sidebar's Lenses tab.
