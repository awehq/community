# awe-lens-stack-overflow

A **awe Lens** that renders `stack.overflow`-matched URLs as a clean structured view inside an awe chat.

> Show a Stack Overflow question with its top-scoring answer body, vote counts, and accepted-answer status — pulled live from the StackExchange API.

## Install

```bash
awe-core lenses install https://github.com/awehq/community#lenses/stack-overflow
```

Or paste the URL into **+ Add lens** in the gateway sidebar's Lenses tab.
