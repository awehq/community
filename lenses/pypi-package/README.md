# awe-lens-pypi-package

A **awe Lens** that renders `pypi.package`-matched URLs as a clean structured view inside an awe chat.

> Show a PyPI package summary: latest version, summary, license, author, project URLs, and required Python version — pulled live from the PyPI JSON API.

## Install

```bash
awe-core lenses install https://github.com/awehq/community#lenses/pypi-package
```

Or paste the URL into **+ Add lens** in the gateway sidebar's Lenses tab.
